# influ-JSON — AI UGC Production Studio

Estudio local de producción de Contenido Generado por Usuario (UGC) con influencers virtuales sintéticos.

## 🚀 Filosofía del Proyecto (Cero Costo Primero)
- **Sin suscripciones ni APIs pagadas**: Utiliza Pollinations (gratis) y almacenamiento local SQLite.
- **Identidad Consistente**: Esquema `character_lock` en JSON para mantener la cara, cuerpo y personalidad del influencer a través de múltiples prompts en ChatGPT, Gemini, Claude o Meta AI.

## 🛠️ Inicio Rápido
```bash
# Instalar dependencias
npm install

# Iniciar servidor local
npm start
```
Abrir navegador en `http://localhost:3000` (PIN predeterminado: `1234`).

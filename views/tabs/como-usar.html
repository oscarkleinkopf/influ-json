Cómo usar el Studio

Crea influencers consistentes sin pagar face-lock. El JSON es tu ancla; Pollinations es opcional e inestable. Los chatbots gratis hacen el resto.

El flujo en cuatro movimientos

Una sola persona. Muchas escenas. Cero tarjeta.

  1. 01

    Elige nicho y crea

    Beauty, Fitness o Moda. El preset rellena tez, cuerpo y voz para que el character_lock nazca fuerte.

  2. 02

    Guarda en tu portafolio

    Al guardar, el influencer queda en SQLite bajo tu perfil. Nadie más mezcla tus creaciones.

  3. 03

    Copia el JSON (recomendado)

    Pégalo en ChatGPT, Gemini o Claude free. Misma cara en retrato, cuerpo entero, bikini o producto. Sin red de imagen también sirve.

  4. 04

    Boceto local o kit marca

    Pollinations = boceto opt-in (suele pedir token / pollen). Si falla (401/402) o hay 429: Modo offline + Copiar JSON. El kit ZIP lleva lock + 4 packs + guión.

La regla de oro

Si la cara o la tez cambian, re-pega el CHARACTER LOCK y vuelve a pedir la imagen.

  • Fijo cara, tez, pelo base, proporciones
  • Variable pose, ropa, fondo, producto
  • Recomendado Copiar JSON / packs → chatbot free
  • Opcional Generar boceto (opt-in · token) — si falla, Copiar JSON / Modo offline

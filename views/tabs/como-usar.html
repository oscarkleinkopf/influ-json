Cómo usar el Studio

Crea influencers consistentes sin pagar face-lock. El JSON es tu ancla; Pollinations es opcional. Los chatbots gratis hacen el resto.

El flujo en cuatro movimientos

Una sola persona. Muchas escenas. Cero tarjeta.

  1. 01

    Influencers → crear o inspirar

    En Ficha / Editor: «Crear influencer» o «Importar referencia» / Inspirar desde foto. Presets Beauty / Fitness / Moda refuerzan el character_lock.

  2. 02

    Guardar → aparece en Portafolio

    Al guardar, el influencer queda en SQLite bajo tu perfil. Vuelve a Influencers → Portafolio para verlo.

  3. 03

    Lock & Packs → Copiar JSON

    El botón verde Copiar JSON pega el pack cuerpo entero. Otras tomas viven en Packs ▾. Pégalo en ChatGPT / Gemini / Claude free.

  4. 04

    Boceto opt-in o kit marca

    Pollinations = boceto opt-in (token / pollen). Si falla (401/402) o hay 429: chip Offline en el sidebar + Copiar JSON. El kit ZIP lleva lock + packs + guión.

La regla de oro

Si la cara o la tez cambian, re-pega el CHARACTER LOCK y vuelve a pedir la imagen.

  • Fijo cara, tez, pelo base, proporciones
  • Variable pose, ropa, fondo, producto
  • Canónico Copiar JSON → chatbot free
  • Opcional Generar boceto (opt-in · token) — si falla, Copiar JSON / Offline

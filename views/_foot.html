influ-JSON es un Studio local

Esta web se publica desde main, pero solo como estáticos. El PIN, el roster y character_lock necesitan Node + SQLite en tu máquina — aquí no hay API. 

git clone https://github.com/oscarkleinkopf/influ-json.git
cd influ-json
# Windows: doble clic start-studio.cmd
# Linux/macOS:
./start-studio.sh

Necesitas Node 18+. El launcher instala deps, abre el navegador en http://127.0.0.1:3000 · PIN 1234. Alternativa: npm install && npm start.

Perfiles de usuario (local)

Varios emprendedores en el mismo Studio, cada uno con su PIN y su roster. Sin nube ni OAuth. Las filas no abren otra pantalla: renombrar, cambiar PIN o eliminar.

Solo miembros sin influencers cuyo nombre parece de harness (Member Sec*, MetricsMem_*, Onboard_*, Smoke*). No toca Administración ni perfiles con roster.

Invitaciones (Administración)

Genera códigos para que otros prueben el Studio. Cada invitado obtiene un perfil aislado — sus creaciones no se mezclan con las tuyas.

Código:

Dos caminos

Camino A · Chatbots gratis (default): Copiar JSON, sin NVIDIA. Camino B · GPU NVIDIA local (opt-in): Ollama / LM Studio (texto) + Locally Uncensored / Comfy (imagen). Receta G513R y LoRA solo en este modo.

Métricas de generación (local)

Contadores gratis en SQLite: cuántos retratos / variantes / fallos 429 por perfil. Prepara la decisión de Replicate sin pagarlo.

Audit log (local)

Últimas 50 acciones sensibles: archivar, borrar, exportar, backup. Solo lectura — solo Administración.

Backup SQLite (Administración)

Copia local de la base en data/backups/. Gratis, sin nube. Se conservan los últimos 10 (env BACKUP_KEEP). Restaurar pide reiniciar el servidor.

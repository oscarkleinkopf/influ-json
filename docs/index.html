influ-JSON

Studio local para influencers virtuales consistentes

Genera prompts y JSON character_lock y pégalos en chatbots gratis. GitHub Pages no ejecuta el Studio: corre en tu PC.

Abrir repositorio

Arranque en 4 líneas

Necesitas Node.js. El PIN por defecto es 1234.

git clone https://github.com/oscarkleinkopf/influ-json.git
cd influ-json
npm install
npm start

Luego abre http://127.0.0.1:3000. GitHub Pages publica la rama main (raíz del repo): esa URL es informativa; el Studio completo (PIN, login Google opt-in, SQLite) solo corre en local con npm start.
